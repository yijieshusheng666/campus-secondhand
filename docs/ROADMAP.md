## 怎么验证"看得见"

每完成一项，至少留下一条可复查的证据：

| 手段 | 命令 / 方式 |
|---|---|
| 界面截图 | `docs/verify/` 下按 `编号-描述.png` 命名 |
| 接口级验证 | `curl` 命令与真实响应贴在提交说明里 |
| 回归 | `cd ai-service && python -m pytest tests/ -q` 全绿 |
| 关联提交 | 提交信息里带编号，如 `feat(ai): A2 语义搜索接入首页` |

## 推进顺序（可退可进）

1. **P1（做深）**：A1 ✅ → A2 ✅ → A5 ✅ —— **P1 完成**
2. **P2（做通）**：B1 ✅ → **B2** → B3 → B4 ← 下一步
3. **P3（做通）**：C1 → C2 → C3 → C4
4. **P4（做薄，可砍）**：A3 → A4 → A6

时间紧张就从 P4 往前砍。
